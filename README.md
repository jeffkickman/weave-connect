# Weave Connect

Public-facing prototype for mutual offer/need matching.

**This is a standalone prototype.**
It is completely separate from Weave Time (`weave-route`) and the Medicare Agency CRM.

## Live on phones

**https://jeffkickman.github.io/weave-connect/**

Open that link on any phone. Add to Home Screen:
- iPhone: Share → Add to Home Screen
- Android: menu → Add to Home screen / Install app

## What it does
- People post what they offer and what they need
- Simple mutual matching scores connections
- Open Threads feed
- Local-first seed data for Andalusia / Covington County

## Philosophy
We don’t just connect. We weave.
Human · AI · Tech · Spirit — stronger together.
